# Credentialed write for one repository, {arg}: the github-read set plus push, LFS
# upload, and REST mutations (profile.conf supersedes a github-read instance with the
# same arg). The advertisement admits both services, in regex form deliberately: q:
# constraints key by param name, so a second q:service= token would silently win
# rather than widen. git-receive-pack carries no git-protocol pin — a push negotiates
# protocol v0. The LFS grant widens from the batch endpoint to info/lfs/** (locks and
# verify ride the same prefix). The locks API authenticates with the PAT, so injection
# stays on that prefix — and if GitHub ever points upload-verify at it, the
# lfs.github.com split below applies here too. lfs.github.com is two lines, batch
# first — first match wins, so the order is load-bearing. The batch line keeps
# inject_auth because git-lfs sometimes derives lfs.github.com as its batch endpoint
# (the derivation is unstable). Every other path on that host is an action href from
# a batch response, whose short-lived Authorization must pass verbatim — the PAT
# injected over it makes GitHub answer 403 on upload-verify — so the catch-all pins
# h:authorization and carries no inject_auth. The api.github.com grant is two lines
# because repos/{arg}/** compiles to a pattern whose literal slash must be present —
# the bare repos/{arg} line is what admits the repo-root call itself. GitHub REST
# refuses a request that carries no User-Agent (403, Request forbidden by
# administrative rules) and reads accept to select the API media type; neither header
# is baseline, so the api lines forward both with h:~.+ pins. The S3 upload
# authorizes itself with AWS
# SigV4 carried in request headers (authorization, x-amz-date, x-amz-content-sha256),
# and the signature must pass or S3 answers 403 — h:* on that line is deliberate on
# this self-authorizing endpoint. Its rule must still carry no inject_auth — a second
# Authorization header makes S3 answer 501 — and setup.sh scopes the stub away from it
# for the same reason. The presigned download host, github-cloud.githubusercontent.com,
# carries its credential in the query string and stays query-only.
